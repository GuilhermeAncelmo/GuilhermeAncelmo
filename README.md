# Guilherme Ancelmo

Desenvolvedor de software com experiência prática na construção de aplicações web, APIs e ferramentas para operações de TI. Trabalho com **Python, React, TypeScript e PostgreSQL**, conectando interfaces, regras de negócio e dados. Também exploro aplicações de IA.

## Projetos em destaque

- **[Gestão de ativos de TI](https://github.com/GuilhermeAncelmo/ativos-conversys)** — inventário, estoque, movimentações e importação de planilhas. Backend em Python/FastAPI, frontend em React/TypeScript e PostgreSQL na configuração Docker.
- **[FinPilot](https://github.com/GuilhermeAncelmo/FinPilot)** — aplicação de finanças pessoais em desenvolvimento, com React, TypeScript, Express e Prisma.
- **[Service Desk](https://github.com/GuilhermeAncelmo/Service-Desk)** — protótipo de chamados de TI com React, Express, SQLite e acompanhamento de SLA.

## Tecnologias

**Backend:** Python, FastAPI, Flask, Node.js, Express, APIs REST  
**Frontend:** React, TypeScript, JavaScript, Vite  
**Dados:** PostgreSQL, SQLite, SQLAlchemy, Prisma
